무한루프 강구 열처리 합성 시연 — 보관용 확장안
기준일 2026-10-26
현재 1차 MVP는 KAMP 염욕 열처리 실측자료이며 시작하기.txt를 먼저 확인한다.
이 파일은 별도로 보관한 강구 합성 시연만 설명한다.

1. 정한 개발 기준
- 대상: 100Cr6 계열 강구, 직경 10 mm, 담금질·뜨임 공정 1종.
- 예측: 열처리 완료 후 경도검사 전에 LOT별 부적합 위험 점수 제공.
- 사용: 검사 우선순위와 공정조건 점검. 최종 출하판정이나 설비 자동제어는 제외.
- 시연 판정: LOT마다 가상 경도검사 5개. 60~66 HRC를 벗어난 측정값이 하나라도 있으면 부적합(1).
- 재질·직경·샘플 수·판정 규칙과 모든 공정 중심값은 소프트웨어 시연 설정이다.
  제조사 공개 경도 범위를 참고했지만 수요기업의 승인 규격 또는 실제 설비 레시피를 뜻하지 않는다.
- 기술: Python 3.12 / FastAPI / React / SQLite. 현재 패키지에는 데이터·모델·API·저장 기능이 있다.
  React 업로드·매핑·위험 목록·상세 화면은 다음 개발 단계이다.

2. 바로 사용할 자료
data/process.csv: 1,000 LOT, 500개 열처리 작업, LOT당 공정 요약 1행.
data/inspection.csv: 가상 경도검사 5,000행.
data/labels.csv: 시연 판정 규칙으로 계산한 LOT 정답 1,000행.
data/열처리_합성데이터.xlsx: 공정입력·경도검사·LOT판정 3개 시트.
data/demo_upload.csv: 영문 컬럼 시연용 20 LOT.
data/demo_upload_korean.csv 및 mapping_korean.json: 한글 컬럼 매핑 예제.
data/demo_errors.csv: 중복 LOT, 필수 결측, 다른 재질·직경, 범위 오류 예제.
config.json: 대상 규격, 8개 입력 변수, 시연 판정 기준, 시드 및 입력 검사 범위.
results/benchmark.json: 모델 비교·분할·최종 평가·변수 중요도·환경 버전.
results/verification.json: 업로드·매핑·정답 누수 방지 등 검증 결과.
results/demo_prediction.json: 20 LOT 예측 예제.

모든 CSV의 data_source=synthetic_demo이며 실제 기업 측정 기록이 아니다.
공정 CSV와 검사 CSV는 의도적으로 분리했다. 경도나 LOT 정답을 예측 입력으로 넣지 않는다.
공정 CSV의 임의 시각은 순서 분할을 시험하기 위한 가상 시각이다.

3. 컬럼과 생성 가정
lot_id: 생산 묶음 식별자 / heat_run_id: 공동 열처리 작업 식별자.
process_end_at: 공정 완료 시각 / material_grade: 100Cr6 / diameter_mm: 10.
austenitize_mean_c: 가열 단계 평균온도(섭씨), 시연 중심값 840.
austenitize_dev_c: 840도 기준 최대 절대편차를 표현하는 시연 요약값(섭씨).
hold_min: 가열 유지시간(분), 시연 중심값 35.
quench_oil_c: 냉각유 온도(섭씨), 시연 중심값 60.
transfer_sec: 이송 지연시간(초), 시연 중심값 8.
temper_mean_c: 뜨임 평균온도(섭씨), 시연 중심값 180.
temper_hold_min: 뜨임 유지시간(분), 시연 중심값 90.
load_kg: 장입량(kg), 시연 중심값 100. 같은 작업 내 두 LOT가 공유하는 작업 전체 장입량.

generate_data.py가 고정 시드 20261026으로 공정값, 가상 경도 측정값, LOT 판정을 생성한다.
이 스크립트는 CSV를 재생성한다. 동봉 Excel은 현재 설정의 고정 사본이므로 설정을 바꾼 뒤에는 재생성된 CSV를 사용한다.
가열 온도 편차의 제곱, 뜨임 온도, 냉각유·이송 지연의 상호작용과 작업별·측정별 잡음을 조합한다.
정상 주변 조건 76%, 가열 온도가 낮은 조건 14%, 뜨임 온도가 높은 조건 10%를 가정했다.
이 비율, 온도·시간 중심값 및 경도 생성식은 현장 통계나 검증된 금속학 모델에서 추정한 값이 아니다.
생성식의 숫자 계수는 generate_data.py에 공개되어 있다. 원시 센서 시계열은 이번 패키지에 포함하지 않는다.
실제 적용 전에는 검사 위치·표면곡률 보정·경도 척도·샘플링·LOT 판정을 도메인 멘토에게 검토받는다.

4. 재현과 실행
다른 PC에서는 Python 3.12 가상환경에서 다음 순서로 실행한다.
  python -m venv .venv
  .venv\Scripts\python -m pip install -r requirements.txt
  .venv\Scripts\python generate_data.py
  .venv\Scripts\python train_models.py
  .venv\Scripts\python verify_pipeline.py
  .venv\Scripts\python -m uvicorn app:app --host 127.0.0.1 --port 8765
브라우저에서 http://127.0.0.1:8765/docs 를 열면 API 호출 화면을 사용할 수 있다.

현재 PC의 임시 검증 환경은 run_local.ps1로 실행한다.
API: /preview 파일 컬럼 확인, /predict 파일과 매핑으로 예측, /runs/{id} 결과 다시 조회,
     /schema 데이터 구조, /model 합성데이터 벤치마크, /health 상태 확인.
예측용 Excel은 첫 번째 시트가 공정입력인 파일을 사용한다.
입력은 UTF-8 CSV 또는 xlsx, 최대 10 MB·10,000행이다. 업로드는 로컬에서 처리한다.
모델은 패키지에서 생성한 모델만 읽는다. 사용자 모델 파일 업로드는 지원하지 않는다.

5. 모델 검증
시간순 600 LOT 학습 / 200 LOT 검증 / 200 LOT 최종 평가.
같은 heat_run_id가 두 구간에 겹치지 않는다. 전처리는 학습 구간에서만 맞춘다.
로지스틱 회귀, 랜덤포레스트, XGBoost를 동일 분할에서 비교했다.
검증 구간에서 F2(재현율을 더 중시)를 기준으로 모델과 임계값을 선택했다.
선택 이후에만 최종 평가 구간을 사용했다. 합성자료의 좋은 성능은 생성 가정을 반영한다.
현재 선택 모델: XGBoost. 시연 주의 임계값 0.15.
최종 합성 평가 200 LOT: 실제 부적합 37, 발견 33, 미탐 4, 오탐 9.
정확도 93.5%, 정밀도 78.6%, 재현율 89.2%, F1 0.835.
전체를 정상으로 판단하는 기준모델의 정확도는 81.5%, 부적합 재현율은 0%.
위험 점수는 확률 보정을 검증한 실제 불량확률이 아니다. 변수 중요도는 인과 원인이 아니다.

6. 담당과 5주 계획
이강민: 범위·판정 기준·일정·검증 결과 총괄.
박상민: React 업로드·매핑·위험 목록·상세 화면.
양희수: 데이터 생성·전처리·모델·검증.
장정원: FastAPI·SQLite·예측 연동·실행패키지.
1인 주 6~8시간, 팀 주 24~32시간. 5주 120~160인시.
내부 일정: 10/29~11/4 기준 검토와 화면 골격, 11/5~11/11 업로드·매핑 연결,
11/12~11/18 결과 화면·변수 분석, 11/19~11/25 통합·멘토 피드백,
11/26~12/2 오류 수정·보고서·매뉴얼·리허설. 공식 제출일에 맞춰 조정한다.
핵심 완료 기준: 서로 다른 컬럼명의 파일 2개를 같은 입력으로 처리하고, 예측 보류 사유를
행 단위로 표시하며, 위험 점수·공정편차·모델 버전을 확인할 수 있게 한다.

7. 공개 자료와 실제 데이터 연계
General Bearing 카탈로그의 Balls 항목(파일 29쪽)은 52100 강구의 60~66 HRC 범위를 소개한다.
https://cdn.skfmediahub.skf.com/api/public/0947488ecec83348/pdf_preview_medium/0947488ecec83348_pdf_preview_medium.pdf
이 자료의 범위를 시연 기준으로 참고했다. 표본 5개·하나라도 벗어나면 부적합은 우리 시연 규칙이다.

KAMP 열처리 품질보증 AI 데이터셋 상세정보:
https://www.kamp-ai.kr/aidataDetail?DATASET_SEQ=60
원본 ZIP과 가이드북을 2026-10-26 내려받아 프로젝트 참고자료에 저장했다.
실제 품질 정답은 자동차 부품 염욕 열처리 136작업의 양품·불량 수량이며 경도 측정값은 없다.
KAMP 가공자료와 모델은 별도 kamp 폴더에 있다. 강구 합성자료의 검증 결과와 혼용하지 않는다.
개발 시작 ZIP에는 대용량 KAMP 원본과 개인화된 가이드북이 포함되지 않는다.
https://www.kamp-ai.kr/userguide

8. 면담에서 요청할 검토
정한 제품·경도 범위·샘플링 규칙이 기업 수요에 맞는지 확인한다.
현재 예측 시점(열처리 완료 후 검사 전)이 적절한지 검토한다. 공정 중 예측이 필요하면 입력 시점을 다시 자른다.
합성 가정을 실제 조건으로 바꾸는 데 필요한 변수 범위와 익명 검사 샘플을 요청한다.
실측자료가 들어오면 데이터 출처와 판정 정의를 분리하고, 합성 결과와 실제 평가를 각각 보고한다.
