# 무료 공개 체험 배포

React 화면과 FastAPI 추론 API를 **하나의 Render 주소**에서 제공합니다. 배포 대상은 무료 Python 웹 서비스 1개이며 유료 DB·디스크를 만들지 않습니다. 저장소는 Private 상태를 유지합니다.

## 공개 서버의 동작

- 로그인 없이 접속하고 합성 예제 120개 작업으로 실제 모델 추론을 체험합니다.
- CSV/Excel 업로드, 항목 연결, 검증, 분석, 결과 CSV 다운로드를 사용할 수 있습니다.
- 파일 하나당 최대 10MB·500행입니다. 로컬 기본 모드는 기존 10,000행 제한을 유지합니다.
- 분석 결과와 파일명은 모든 방문자가 볼 수 있습니다. 개인정보나 기업 비공개 자료는 업로드하지 않습니다.
- 이력은 최근 20건만 저장합니다. 서버 재시작·재배포 시 삭제될 수 있으며 영구 저장을 보장하지 않습니다.
- 무료 서버는 미사용 시 대기 상태가 되어 첫 접속에 시간이 걸릴 수 있습니다.

## 배포 파일

`scripts/build_public_demo.py`가 실행에 필요한 파일만 `tmp/public-demo`에 모읍니다. API 코드, 입력 스키마, 모델, 공개용 집계 통계, 독립 생성 합성 예제, 빌드된 화면이 대상입니다. 실측 CSV, 로컬 `benchmark.json`, 개인 SQLite 이력, 원본 문서, 개발 환경은 실행 패키지에 포함하지 않습니다. 각 파일의 SHA-256은 패키지의 `manifest.json`에 기록합니다.

`ICT_PUBLIC_DEMO=1`일 때는 로컬 실측 파일이 존재해도 실측 예제 다운로드를 막고 공개용 통계와 독립 생성 합성 예제만 사용합니다. 업로드 파일은 사용자가 공개해도 되는 자료여야 합니다.

## Render 설정

구성은 저장소 루트의 `render.yaml`에 기록했습니다. 연결 도구로 서비스를 직접 만들 때도 다음 값을 적용합니다.

| 항목 | 값 |
|---|---|
| 유형 / 요금 | Web Service / Free |
| 위치 / Python | Singapore / 3.12.14 |
| 빌드 | `pip install -r 준비패키지/requirements-lock.txt && python scripts/build_public_demo.py` |
| 시작 | `uvicorn app_kamp:app --app-dir tmp/public-demo/준비패키지 --host 0.0.0.0 --port $PORT --workers 1` |
| 공개 체험 모드 | `ICT_PUBLIC_DEMO=1` |
| 이력 경로 | `ICT_DB_PATH=/tmp/ict-public-demo/runs.sqlite3` |
| 수치 연산 스레드 | `OMP_NUM_THREADS=1`, `OPENBLAS_NUM_THREADS=1`, `MKL_NUM_THREADS=1` |
| 자동 배포 | 끔 — 변경 검증 후 수동 배포 |

프런트 화면을 바꾸면 먼저 `frontend`에서 `pnpm build`를 실행하고 생성된 `dist`까지 커밋합니다. Render에서는 저장소에 포함된 빌드 결과를 사용합니다. `/health`가 모델을 읽어 정상 상태를 반환하는지 확인하고, 홈 화면의 **합성 예제 결과 보기**로 추론과 이력 저장을 점검합니다.

## 검증 명령

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -p 'test*.py' -v
.\.venv\Scripts\python.exe scripts/build_public_demo.py
$env:ICT_TEST_URL='http://127.0.0.1:8782'
node frontend/tests/e2e.mjs
```

공개 모드 API 테스트는 별도 임시 DB를 사용하며 실측 예제 차단, 공개 통계 선택, 실제 합성 추론·내보내기, CSV/Excel 500행 제한, 이력 20건 보관을 확인합니다.

공식 운영 조건: [Render 무료 서비스](https://render.com/docs/free), [FastAPI 배포](https://render.com/docs/deploy-fastapi).
