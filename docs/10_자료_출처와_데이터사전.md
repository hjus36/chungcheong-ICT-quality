| 항목 | 내용 |

실험 설계로 설정값(SET_*)을 바꿔 가며 생산한 자료다. 한 행은 사출 사이클 하나이며, 사이클마다 육안 검사 결과(싱크마크, 미충전, 줄무늬 등)와 사이클 중·후 측정값이 있다.

### 접두사와 측정 시점

| 접두사 | 내용 | 측정 시점 | 모델 입력 |
|---|---|---|---|
| MET | 식별자·시각·실험 번호·재료·재료 수분 | 메타 / 생산 전 | 수분만 후보 |
| SET | 실험 계획의 목표 설정값 | 생산 전 | 후보 |
| ENV, DRY | 생산 공간 온습도, 건조기 | 생산 전 | 후보 |
| QUA, DXP, E77 | 사출기 품질 테이블, 센서 추출값, EUROMAP77 | 사이클 중 | 후보 |
| TCE, TCN | 금형 온조기 (취출측, 노즐측) | 사이클 중 | 후보 |
| CALC | 스크류 위치에서 계산한 값 (PP만) | 사이클 중 | 후보 |
| DOS | 도징 시스템 | 사이클 중 | 후보 (대부분 시계열이라 제외) |
| IR, CV | 탈형 후 IR 카메라, 일반 카메라 치수 | 사이클 후 | **제외** |
| SCA | 냉각 후 무게 | 사이클 후 | **제외** |
| SIM | Moldex3D 시뮬레이션 | 오프라인 | **제외** |
| LBL | 육안 검사 라벨 | 결과 | **제외** (타깃 `LBL_NOK`) |

이 표는 `ml_workflow/config/columns.yaml`의 `prefix_stage`와 같다. 측정 시점은 데이터 설명서 기준이며, 판단이 바뀌면 YAML만 고친다.

## 2. 서비스 입력 데이터 사전

**기준 파일은 `준비패키지/release/data_dictionary.json`이다.** 학습 워크플로우의 `07_release`가 만들고 `promote.py`가 복사한다. 손으로 고치지 않는다. 특징 설명·단위·허용 범위 규칙은 `columns.yaml`의 `feature_info`에서 온다.

현재 버전 `probayes-im-v2-im_v2_r2`:

| 이름 | 구분 | 필수 | 단위 | 허용 범위 | 정상 참고 구간 | 원본 열 |
|---|---|:-:|---|---|---|---|
| part_id | 메타 | ✓ | — | — | — | MET_MachineCycleID |
| cycle_start_at | 메타 | ✓ | 시각 | — | — | MET_TimeCycleStart |
| cycle_end_at | 메타 | ✓ | 시각 | — | — | MET_TimeCycleEnd |
| data_source | 메타 | ✓ | — | ProBayes_IM_v2 / synthetic_im | — | — |
| DXP_HoldingPressure1 | 특징 | ✓ | bar | 0 ~ 5000 | 98.9 ~ 350.5 | 같음 |
| CALC_InjectionStroke | 특징 | 대체 | mm | 0 ~ 1000 | 136.9 ~ 149.2 | 같음 |
| material | 선택 |  | — | — | — | MET_MaterialName |
| actual_label | 선택 |  | 0/1 | 0, 1 | — | LBL_NOK |

- 허용 범위는 물리적으로 불가능한 값을 거르는 범위이고, 정상 참고 구간은 학습 정상 부품의 5~95백분위다. 둘 다 공정 규격이 아니다.
- 필수/대체는 학습 자료(dev)에서 결측이 있었는지로 자동 결정한다.
- `excluded_input_prefixes`: `LBL_`, `IR_`, `CV_`, `SCA_`, `SIM_` — 업로드 매핑에서 특징으로 연결할 수 없다.

## 3. 합성 예제 정의

| 파일 | 내용 |
|---|---|
| `준비패키지/share/synthetic_demo.csv` | 120행, 출처 `synthetic_im`, 2026-11-02 08:00부터 60초 간격 사이클 |
| `준비패키지/share/test_upload.csv` | 20행 + 오류 행 5종(중복 ID, 허용 범위 초과, 필수 특징 누락, 날짜 오류, 실제 판정 2) |
| `준비패키지/share/synthetic_definition.json` | 생성 규칙 전체, 특징별 범위, 파일 해시, 기준 release 버전 |

규칙(`ml_workflow/config/synthetic.yaml`): 각 특징을 정상 참고 구간을 양쪽으로 35% 넓힌 범위(허용 범위 안)의 균등분포에서 독립으로 뽑는다. 재료는 PP·ABS 무작위, ABS 행의 `CALC_*`는 비운다(원본도 PP만 계산). 선택 특징의 10%를 비워 결측 대체 경로를 시험한다. `actual_label`은 모델 위험도 p로 Bernoulli(p) 추출한 **가상값**이다. 원본 행은 쓰지 않는다.
