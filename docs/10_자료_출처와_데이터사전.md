KAMP 자료는 출처 표시·인용자료 안내가 있는 데이터이다. KAMP원본 다운로드 동의는 기존 대화에서 승인되었다. 이번 추가자료는 공개 UCI SECOM이며 CC BY4.0을 확인하고 확보했다. 이메일은 보내지 않았다. 가이드북은 개인 다운로드 정보를 포함하므로 Git에서 제외한다. 제공처의 공개 열람·다운로드와 2차 재배포 권리는 같은 개념이 아니다. 현재 로컬 개발자료이며 외부 공개 전 원본 및 가공자료의 이용조건을 확인한다.

## 공통 필드

| 항목 | 형식·단위 | 의미 |
|---|---|---|
| batch_id | 문자열 | 원천 배정번호. 파일 내 유일해야 함 |
| process_start_at / process_end_at | ISO 날짜·시각 | 센서 관측 시작/종료. 시간대 생략 시 한국시간 |
| data_source | 열거 문자열 | KAMP_heat_quality_60 또는 synthetic_kamp60. 한 파일에 한 출처 |
| item_code | 선택 문자열 | 원본에 없으면 생략. 임의 실측 품목을 만들지 않음 |
| total_count / good_count / defect_count | 선택 정수·개 | 총수량>0, 품질수량>=0, 정답 전용 |
| *_Avg | 실수 | 작업 안에서 관측된 센서값의 평균 |
| *_Std | 실수>=0 | 작업 안 표본 표준편차, ddof=1 |

센서 18종은 건조 1·2존 OP, 건조로 온도 1·2 Zone, 세정기, 소입1·2·3·4존 OP, 소입로 CP 값, 소입로 온도 1·2·3·4 Zone, 솔트 컨베이어 온도 1·2 Zone, 솔트조 온도 1·2 Zone이다. 각 센서당 평균·표준편차 2열로 36개이다. OP/CP는 %, 나머지는 °C이며 표준편차 단위는 차이값이다. CP 모니터 중복 채널은 제외했다. 상세 근거는 KAMP 가이드북 데이터 정의 표와 기존 감사 JSON에 있다.

## 전처리와 연결

원시센서 파일은 CP949로 청크 읽기하고, 배정번호·관측시각 중복을 감사한 뒤 작업별 관측값 평균/분산을 누적한다. 원시 결측을 전체 자료 평균으로 미리 채우지 않는다. 작업별 품질표와 배정번호·출처로 1:1 연결하고, 양품+불량=총수량을 확인한다. 원본에는 경도 측정이 없다.

학습 시 결측값과 스케일은 학습 자료만으로 fit한다. 웹에서는 소수의 특성 결측만 학습 중앙값으로 채운다. 변환/대체 원값은 저장 결과에서 비교한다. 정답수량·상대적 라벨은 추론 특성에서 제외된다.

## 합성 방법

학습 자료의 36차원 작업 벡터를 seed=20261101로 120회 복원 추출하고, 특성별 학습 표준편차의 0.12배 정규 잡음을 더한다. 평균 OP/CP는 0~100, 표준편차는 0 이상으로 제한한다. 변수 간 결합은 원래 벡터를 재표집하여 일부 보존하지만 실제 물리 시뮬레이터는 아니다.

첫째/셋째 특성의 학습 표준화값 z1,z2로 `p=clip(0.0002+0.0002*z1²+0.00015*max(z1*z2,0)+U(0,0.0003),0,0.02)`를 가정하고 `Binomial(10000,p)`로 불량수량을 만든다. 시각·ID·품질수량은 모두 가상이다. 이 자료는 모델 학습·선정·성능 평가에 포함하지 않는다.

## 무결성 근거

`kamp/audit.json`은 최초 전체 원본 감사이다. 이번 `tests/verify_data.py` 실행은 원본 540,717,794바이트 CSV 및 16,460바이트 Excel의 SHA-256이 기존 감사와 일치함을 확인했고, 가공 136행 연결·특성값·불량률·수량 합계를 다시 검증했다. 원본을 새로 전체 집계한 것으로 표현하지 않는다. 결과는 `verification/data_results.json`이다.

## 추가 확보한 SECOM과 검토한 열처리 후보

McCann, M. & Johnston, A. (2008). **SECOM [Dataset]**. UCI Machine Learning Repository. [DOI10.24432/C54305](https://doi.org/10.24432/C54305), [공식 소개](https://archive.ics.uci.edu/dataset/179/secom), [CC BY4.0](https://creativecommons.org/licenses/by/4.0/).

`experiments/quality_20261101/sources/uci_secom/`에1,964,989바이트 ZIP과 원문3개파일을 확보했다. 출처·다운로드UTC·파일별SHA256·용도는 provenance.json에 있다. 원본 숫자행렬은1,567×590, 라벨은1,567행(-1합격/+1불합격,검사시각)이다. 제공처 설명의591특성과 숫자파일590열의 차이를 기록하고 가상열을 추가하지 않았다. 실패104개, 학습/검증/평가820/367/380행이다.

입력은 signal_001~signal_590으로만 이름을 부여했다. 물리 단위·변수 뜻·LOT/설비식별자는 제공되지 않아 미상으로 표시한다. 검사시각은 시간분할에만 사용하고 입력특성에 넣지 않는다. 행 식별 entity_id는 원본 행번호이며 실제 LOT번호가 아니다. 원본은 수정하지 않았고 시간분할·결측처리·특성선택·학습은 본 프로젝트에서 수행했다. 열처리와 합치지 않으며 웹 업로드 대상도 아니다.

KAMP공정최적화61은 기존60과 센서행수/정답수/첫작업이 일치해 별도 독립자료로 세지 않았다. 예지보전43은 제품검사 정답의 독립성을 확인하지 못했다. 명장 플랫폼 후보는 DNS접속 실패로 확보하지 못했다. 상세 근거와 URL은 `experiments/quality_20261101/source_review.json`에 있다. 모든 열처리 공개자료가 부적합하다는 뜻은 아니다.

## 실험용 파생 데이터 사전

기존 웹 입력 사전 `데이터사전.json`은 그대로 두고, 추가 정의를 `실험_데이터사전.json`으로 분리했다. 관계16개는 기존36특성에서 계산하며 온도평균·온도차·표준편차는°C, CP는%이다. 시간특성35개는5신호군의7통계이며 시간당 추세는°C/h 또는%/h다. 범위·기울기는 기업 허용한계가 아니다. 가열·냉각 실제 단계 정답이 없어 경과시간 처음/마지막20% 창으로 정의했다.

이번에는 원본 센서2,939,722행을 다시 읽어 시간특성을 생성했다. 원래36특성 재집계 파일은 덮어쓰지 않았다. 출력136행/35특성과 원본해시·생성정의는 temporal_manifest.json, 품질연결·민감도·기간별분포는 data_audit.json, 작업일과관측시점 관계는 timing_audit.json에 있다.
