## 성능 개선 작업의 최종 판정

**기존 모델을 교체할 만한 개선 근거는 확보하지 못했다.** 열처리 원본294만행 재분석으로 공정 관계16개와 시간특성35개를 만들고, LR/RF/XGBoost 18후보 및 기존RF대조군을 비교했다. 최고CV후보는 검증 AP0.2290/F2 0.3846으로 기존0.3770/0.6061보다 낮았다. 서비스의 RandomForest0.35, 기존API·입력·이력·화면을 유지했다.

추가로 UCI SECOM실측1,567생산개체·590숫자신호·104실패를 확보했다. 별도 시간순820/367/380분리에서6후보를 비교했고, 선정XGB는 최종380개체에서 AP0.0889, Recall4.3%였다. 이 결과는 열처리모델의 외부검증도, 현장 성능 개선 성공도 아니다.

새 분석 코드·분할·전처리·후보모델·선정잠금·원본해시·평가결과를 `experiments/quality_20261101/`에 보존했다. API11개·실험검증8개·프로세스재시작·주요브라우저흐름을 다시 통과했다. 상세 수치/원인/한계는 문서06, 기술검증은 문서07, 추가출처는 문서10에 있다.

## 완성한 결과

**CSV/Excel 업로드 → 원천 항목 매핑 → 단위/행 검증 → 모델 추론 → 공정편차/변수 분석 → React 대시보드 → SQLite 저장·이력 조회**를 실제로 동작하는 로컬 웹 MVP로 완성했다. 정적 목업이 아니라 FastAPI와 저장된 모델을 호출한다. UI는 한국어이며 데스크톱과 모바일 화면을 검증했다.

대상은 자동차 부품 염욕 열처리 한 공정과 작업별 상대적 고불량률 위험 한 종류이다. 원본 2,939,722센서행과 품질 136작업을 연결한 기존 집계·모델 기반을 재사용했다. 강구 경도 합성자료는 별도 과거 시연으로 보존하고 현재 분석에 섞지 않았다. 현재 동일공정 합성 기능자료 120작업을 추가했다.

## 기능별 구현

업로드는 UTF-8/CP949 CSV와 xlsx, 파일 미리보기, 40필수·4선택 항목 연결, 명시적 °F/K/비율 변환을 지원한다. 행별 중복·결측·형식·수량 오류를 설명하고 유효행만 분석한다. 모델은 품질수량을 입력으로 사용하지 않는다. 점수·실제/가상 불량률·학습 통계 구간을 각각 구분한다.

위험 작업 목록은 검색·검토 필터·페이지 이동·상세 편차·원본/대체/변환값 확인·CSV 내보내기를 제공한다. 변수 화면은 학습 분포·품질 관계·검증 permutation 영향값을 보여준다. 이력은 시각·파일명·자료 출처·모델 버전·입력 해시와 결과를 보관하고 당시 결과를 그대로 복원한다. 기존 DB는 열을 추가해 읽으며 과거 payload는 유지한다.

## 기존 서비스 모델 검증 결과

LR/RF/XGBoost 3종에 train 시간순 CV를 적용했고 검증 기준으로 RandomForest을 선택했다. 보류 36작업 결과는 TP5/FN2/FP23/TN6, Recall 71.4%, Precision 17.9%, F1 0.2857, F2 0.4464, AUC 0.4286이다. 전부 경고하는 F2 기준선 0.5469보다 낮다. 초기 모델보다 재현율은 높지만 오경고가 크게 늘어 성능 개선 달성으로 결론내리지 않는다.

보류자료는 이미 본 개발 참고 자료이고 신규 독립 검증이 아니다. 공정 완료 후 요약값을 사용하므로 조기예측·생산 중 경고를 구현한 것이 아니다. 현재 완료는 **기술적 기능 검증용 MVP**이며, 현장 품질예측 성능이나 불량 감소 효과를 확보한 상태가 아니다.

## 실행·테스트

자동 API 테스트 11개와 브라우저 점검 11개 통과, 실제 프로세스 재시작 후 결과 동일, 원본 해시·작업 연결 일치, Windows 신규 가상환경 설치·프런트 빌드 성공을 확인했다. 상세 증거와 미검증 범위는 `07_검증_결과보고서.md`에 있다.

현재 PC 실행: `powershell -ExecutionPolicy Bypass -File .\scripts\start.ps1` → `http://127.0.0.1:8765`. 다른 PC 최초 설치는 `scripts/setup.ps1`이다. 원본 KAMP 다운로드·추가 학습 없이 동봉 독립 합성 예제와 모델로 시연할 수 있다.

## 다음 현장 적용 조건

기업별 품목·재질·불량유형·검사시각·판정규격과 예측 시점 이전 센서구간을 확보하고, 새 기간/기업의 독립 자료로 누락/오경고 비용을 검증해야 한다. 그 후에 운영 알림 기준·사용자 권한·백업·설비/MES 연결을 설계한다. 추가 공개자료 UCI SECOM을 다운로드해 별도 연구모델로 검증했다. 공유 저장소는 Private로 유지하며 코드·독립 합성 예제·모델·집계 결과·문서를 반영한다. 서버 외부 배포와 이메일 전송은 작업 범위에 포함하지 않는다. 원본과 사용자 자료는 삭제하지 않았다.

## 저장소 공유 정리

기존 실측 예제와 작업별 가공 CSV, 개인화 자료 및 면담 문서는 로컬 보존 후 현재 Git 추적에서 제외한다. 새 독립 합성 예제120행과 최소5작업별 집단 평균 관계도를 제공하며 서비스 모델과 기존 로컬 DB는 유지한다. 이전 커밋의 자료까지 제거한 것은 아니다. [공유 기준](../DATA_USAGE.md)과 [현재 검증 기록](07_검증_결과보고서.md)을 확인한다.
