# 요구사항 정의서

프로젝트: 제조공정 데이터 기반 품질위험 예측 및 공정편차 분석 MVP · 무한루프팀

작성 기준: 2026-11-01. 공식 근거는 로컬 보관 중인 `참고자료/붙임1_공고문 및 과업지시서 (1).pdf` 인쇄 17~18쪽 과제 6이다. 이 문서는 구현된 MVP의 범위와 검증 기준을 기록한다. 공식 원문은 GitHub 배포본에 포함하지 않는다.

## 목적과 범위

분산된 공정 기록을 작업 단위로 정리하고 품질 검토 우선순위와 통계적 공정편차를 함께 확인한다. 사용자는 품질 담당자와 공정 담당자이다. 공정은 **자동차 부품 염욕 열처리**, 판정 대상은 **작업별 상대적 고불량률 위험** 한 종류이다. 입력은 작업 완료 후 집계값이다. 실시간 조기예측·출하판정·설비 자동제어를 구현했다고 주장하지 않는다.

실제 기업별 규격은 제공되지 않았다. 학습 자료 불량률의 상위 25% 경계를 상대적 라벨로 사용한다. 위험 점수는 보정된 불량 확률이나 예상 불량률이 아니다. 통계적 참고 구간(학습 5~95백분위)은 기업 규격이 아니다.

위원평가는 공정·라벨·일정·매핑 화면·지표 구체화와 합성자료 한계 설명을 권고했다. 인터뷰 안내의 약 5주 범위를 내부 계획에 반영한다. 공고의 과거 일정과 내부 일정은 구분하며 기업 현장평가 완료로 표시하지 않는다.

## 기존 상태 대조(착수 시점)

이미 있는 기능: KAMP 원본 2,939,722행 → 136작업 집계, 품질 136행과 1:1 연결, 36특성, 시간순 분리, 3모델 비교, 기본 FastAPI 예측·단건 이력, 별도의 강구 합성 시연. 원본과 기존 결과는 보존한다.

보완 대상: React 화면, 명시적인 검증 단계, 단위 선택·변환, 품질 정답과 입력의 분리, 이력 목록, 상세 분석, 변수 분포·관계, 실행 자동화, 통합 테스트, 현재 구현에 맞는 문서. 기존 `app_kamp.py` 진입점과 전처리 코드를 재사용한다.

사용 시나리오: 담당자가 가공된 작업 CSV를 업로드하고 원천 열을 연결한다. 검증에서 오류행·결측 대체·단위 변환을 확인한다. 분석 실행 후 위험 작업과 편차를 확인하고, 변수 관계와 모델 검증 수준을 보고 검사 우선순위를 참고한다. 이력에서 같은 결과를 다시 조회한다. 품질수량은 선택적 사후 비교용이며 추론 입력에서 제외한다.

성능 기준(내부): 20행 예제 로컬 API 추론 5초 이내를 목표로 측정하며 보장 SLA는 아니다. 대용량 원시센서 CSV는 웹 직접 입력 대상이 아니다. `prepare_kamp.py`로 사전 집계한다. 모델 최소 Recall 목표를 임의로 성공으로 간주하지 않으며 실제 성능과 단순 기준선 차이를 보고한다.
