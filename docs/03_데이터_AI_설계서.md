## 출처와 대상

중소벤처기업부 KAMP, 스마트제조혁신추진단(㈜임픽스), 「열처리 품질보증 AI 데이터셋」, 2022-12-23 등록, 2026-10-26 다운로드. [원본 소개](https://www.kamp-ai.kr/aidataDetail?DATASET_SEQ=60). 원본은 기존 `참고자료/KAMP_열처리_품질보증/`에 있다. 개인 다운로드 정보가 있는 가이드북·원본은 Git 제외를 유지한다. 공개 다운로드가 재배포 무제한을 뜻하지 않으므로 외부 공개 전 제공처 이용조건을 확인한다. 이번 개선에서는 UCI SECOM을 추가 확보해 별도 반도체 모델로 검증했다. 열처리와 합치지 않는다.

염욕 열처리 작업 136개, 센서 2,939,722행·21열, 품질 136행·7열이다. 배정번호와 시각의 중복 및 잘못된 시각은 기존 감사에서 0이다. 품질수량 합계와 136:136 연결을 검증한다. CP 모니터 중복 채널을 제외한 18센서의 작업 내 평균·표본 표준편차(ddof=1)로 36특성을 만든다. 전체 센서행 수를 독립 학습표본 수로 주장하지 않는다.

## 입력 계약

필수 메타: `batch_id`, `process_start_at`, `process_end_at`, `data_source`. 36열은 `kamp/audit.json`의 features 순서이며 각 센서의 `_Avg`, `_Std` 쌍이다. 온도(세정기 포함)는 °C, OP 및 CP는 %이고 표준편차는 해당 단위의 차이값이다. °F/K 및 비율(0~1) 입력은 사용자가 명시한 경우에만 변환한다. 추정 변환을 하지 않는다. 원본 해석 근거는 가이드북 데이터 정의 표이다.

선택 메타: `item_code`. 선택 정답: `total_count`, `good_count`, `defect_count`. 총수량과 불량수량을 함께 입력하면 실제 불량률을 계산한다. 음수·소수 수량, 불량>총량, 양품+불량≠총량은 오류로 처리한다. 정답은 모델 입력에 포함하지 않는다. 실제 원본에 없는 품목·경도·규격을 생성해 실측처럼 표시하지 않는다.

작업 ID 중복은 양쪽 모두 제외하고 알려준다. 날짜는 ISO 형식을 권장하며 타임존이 없으면 한국시간으로 해석한다. NaN은 특성 3개까지 학습 중앙값으로 대체하고, 4개 이상은 행을 제외한다. 숫자 형식 오류·무한값·음의 표준편차는 제외한다. 통계 구간 밖 수치는 삭제/절단하지 않고 편차로 표시한다. 올바른 데이터 소스가 아닌 다른 공정·합성 자료를 조용히 섞지 않는다.

## 라벨과 분리

실측 불량률=불량수량/총수량×100. 학습 집합 불량률 Q3(약 0.049443%, 494.43PPM) 이상을 상대적 고위험 1로 정한다. 기업 불량 규격이 아니다. 모델 점수의 경고 임계값과 이 라벨 경계는 서로 다르다.

기존 달력 경계를 유지한다: 2022년 1~4월 train 78, 5월 validation 22, 6~7월 test 36. 경계에 걸친 작업은 purge한다. 라벨 경계·결측 대체·스케일·참고범위는 train만으로 계산한다. 기본 3모델 결과는 보존한다. 기존 배포 모델의 선정은 검증 F2/Precision을 사용했다. 이번 새 실험은 train 내부 시간순 CV AP로 후보를 고정하고, train OOF에서 검토 부담 제약 아래 임계값을 고정한 다음 검증으로 교체 가능 여부만 판단했다. 교체 기준 미달로 기존 모델을 유지한다.

**기존 test는 이미 결과를 확인한 자료이다. 이번 재평가는 이전에 본 보류자료의 개발 참고 평가이며 새로운 독립 외부 검증이 아니다.** test로 후보나 임계값을 다시 선정하지 않는다. 성능이 낮아도 숨기거나 합성 결과로 대체하지 않는다. Accuracy, Precision, Recall, F1, F2, ROC-AUC, AP와 TP/FN/FP/TN, 전부 주의/전부 통상 기준선을 보고한다. 높은 Recall만으로 불필요한 경고 증가를 감추지 않는다.

## 변수 분석

train 자료의 분위수·분포와 품질 불량률의 Spearman 관계를 제공한다. 선택 모델의 계수/중요도는 모델 연관성, 검증 집합 permutation AP 감소는 예측 기여 참고값으로 표시한다. 상관·기여를 원인이나 최적 공정조건이라고 부르지 않는다. 파일별 상세는 원값·변환값·대체값·학습 5~95% 구간 이탈을 보여준다.

## 합성자료

기존 강구 합성 파일은 별도 과거 시연으로 보존하고 실측모델과 혼합하지 않는다. 현재 UI 기능 검증용으로 train 분포를 바탕으로 염욕 열처리와 동일한 스키마의 가상 작업을 결정론적으로 생성한다. 출처는 `synthetic_kamp60`이며 실측과 같은 파일에 혼합할 수 없다. 가상 품질 결과는 비선형 변수 결합과 난수를 이용한 기능 시험용 가정이다. 이 자료는 학습·벤치마크·실제 성능 주장에 사용하지 않는다.

현재 제한: 독립 라벨 136개, 제품·재질·검사시각·기업 기준 부재, 시기 변화, 전체 작업 집계로 인한 조기예측 불가, 불균형과 불안정한 일반화. 실제 현장 적용에는 시간축에 맞는 추가 배치·제품별 기준·검사 시점과 별도의 신규기간 검증이 필요하다.

## 2026-11-01 개선 실험 설계

원본 센서 전체를 다시 읽어 시간특성35개를 만들고, 기존 요약에서 공정 관계16개를 계산했다. 36/16/51 입력군을 비교하되 fold학습 내부에서 상수·결측·고상관 제거와 ANOVA상위8개 선택을 수행한다. 구체적인 정의·단위는 `실험_데이터사전.json`에 있다. 모든 특성은 작업 종료 시점까지의 센서값으로 계산하며 정답을 참조하지 않는다.

SECOM은1,567생산개체의 라인검사 합격/불합격 별도 사례다. 원본 숫자신호590열, 시간날짜 기준820/367/380분리, fold학습 내부40특성 선택이다. 익명 변수이므로 공정 물리 해석과 열처리 전이는 주장하지 않는다. 웹의 data_source에 추가하지 않으며 실험 전용으로 보관한다.

사전 기준·선정 잠금·모델 적용 결정·구간별 예측은 `experiments/quality_20261101/runs/`에 있다. 최고CV후보가 KAMP검증에서 악화되어 교체하지 않았다. SECOM도 마지막 구간에서 성능이 약해 현장 성능 확보로 표현하지 않는다. 보정된 확률 대신 위험 점수로 표시하는 기존 설계를 유지한다. 상세 수치와 원인은 `06_모델_벤치마크_보고서.md`를 참조한다.
