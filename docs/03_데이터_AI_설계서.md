# 데이터 및 AI 설계서

2026-11-21 · 서비스 모델 `probayes-im-v2-im_v2_r2`. 수치는 학습 워크플로우가 생성한 리포트(`ml_workflow/runs/im_v2_r2/report.md`, 로컬)와 `준비패키지/release/benchmark_public.json`에서 옮겼다. 설계 근거 전문은 [WORKFLOW.md](../ml_workflow/WORKFLOW.md).

## 1. 출처와 대상

ProBayes 「Injection-Molding Production Data with Quality Labels」 v2 (SKZ·Fraunhofer IPA, EUDAT B2SHARE, 2022, CC BY 4.0). 출처·인용·변경 내용은 [DATA_USAGE.md](../DATA_USAGE.md).

| 항목 | 값 |
|---|---|
| 행 | 564 사출 사이클 (한 행 = 부품 한 개) |
| 라벨 | `LBL_NOK` — 정상 409 (72.5%), 불량 155 (27.5%) |
| 실험 그룹 | 실험일 + 실험번호(A01~A16, Z01) = 47개. 모든 그룹의 라벨이 한쪽으로 고정(정상 34, 불량 13) |
| 재료 | PP, ABS |

모든 그룹의 라벨이 고정되어 있으므로 행 단위 무작위 분할은 "어느 실험인지"만 맞혀도 점수가 높아진다. 실제 독립 표본은 564가 아니라 47에 가깝다.

## 2. 입력 특징 결정

컬럼 역할은 `config/columns.yaml`의 규칙으로 자동 판정한다. 데이터 설명서의 측정 시점에 따라 접두사마다 측정 단계를 정하고, **예측 시점(사이클 중) 이후 단계는 입력에서 뺀다.**

| 접두사 | 측정 단계 | 처리 |
|---|---|---|
| SET, MET(수분), ENV, DRY | 생산 전 | 후보 |
| QUA, DXP, TCE, TCN, CALC, DOS, E77 | 사이클 중 | 후보 |
| IR, CV | 탈형 후 | 제외 (사후측정) |
| SCA | 냉각 후 | 제외 (사후측정) |
| SIM | 오프라인 시뮬레이션 | 제외 |
| LBL | 라벨 | 제외 |

시계열 배열·문자열 컬럼도 제외되어 숫자형 후보 86개, 완전 중복 4개를 빼고 82개가 특징 선택에 들어간다.

## 3. 분할과 검증 설계

- **holdout:** 그룹 단위 20% → dev 443행(37그룹, 불량 26.9%) / holdout 121행(10그룹, 29.8%). holdout은 모델 단계 마지막 평가 전까지 쓰지 않는다.
- **CV:** dev 안에서 StratifiedGroupKFold 5-fold × 5회 반복(seed 변경). sklearn 버전에 따라 fold 배정이 달라져 선택이 흔들리는 문제를 줄인다.
- **Filter:** dev만으로 ANOVA F-test + BH-FDR(0.05). 결측 indicator도 함께 평가.
- **Wrapper:** fold마다 학습 부분으로 순위를 다시 계산하고 모델마다 k를 1-SE 규칙으로 고른다(B안).
- **전처리:** 중앙값 대체 + 결측 indicator, LR·SVM은 표준화, 확률 보정(sigmoid, cv=3). 모두 학습 부분에서만 적합한다.

## 4. 모델 선택 규칙

| 순서 | 기준 | 과제 6과의 연결 |
|---|---|---|
| Gate 1 | CV 예측에서 Recall 0.90 지점의 Precision ≥ 0.40 | 예방형 관리: 불량을 놓치지 않으면서 검사량이 감당 가능한가 |
| Gate 2 | 실험일을 하나씩 빼고 학습했을 때 모든 빠진 날의 Recall ≥ 0.50 | 처음 보는 생산 조건에도 불량을 잡는가 |
| 주 지표 | 반복 CV PR-AUC 평균 | 위험 순위의 정확도 |
| 동점 | 1-SE 이내 → 실험일 제외 PR-AUC → Brier → 해석 가능성 | 확장성, 점수 신뢰도, 영향변수 설명 |

## 5. 결과 (반복 그룹 CV, dev)

| 모델 | k | PR-AUC | 기준 | Precision@R0.9 | 실험일 제외 최소 Recall | 결과 |
|---|---:|---:|---:|---:|---:|---|
| **Logistic Regression** | 2 | 0.818 ± 0.23 | 0.252 | 0.501 | 0.50 | **선택** |
| XGBoost | 3 | 0.875 ± 0.21 | 0.170 | 0.618 | 0.00 | Gate 2 탈락 |
| Random Forest | 1 | 0.800 ± 0.27 | 0.083 | 0.533 | 0.00 | Gate 2 탈락 |
| SVM | 1 | 0.762 ± 0.25 | 0.046 | 0.263 | 0.00 | Gate 1·2 탈락 |

XGBoost는 CV PR-AUC가 가장 높지만 한 실험일을 빼면 그날의 불량을 하나도 잡지 못했다. LR만 두 Gate를 통과했다. 선택 특징은 `DXP_HoldingPressure1`(1단계 보압 실제값, 낮을수록 위험)과 `CALC_InjectionStroke`(사출 스트로크, 낮을수록 위험, PP에서만 계산되어 ABS는 결측).

## 6. holdout (개발 참고 평가) 와 기준선

규칙과 설정을 조정하면서 같은 holdout을 이미 확인했으므로 독립 검증이 아니다. 판정 기준은 CV에서 정한 0.252를 고정 적용했다.

| 방법 | PR-AUC | Recall | Precision | F2 | 우선 검토 수 |
|---|---:|---:|---:|---:|---:|
| **LR (선택)** | **0.841** | **1.000** | **0.600** | **0.882** | 60 / 121 |
| 전부 우선 검토 | 0.298 | 1.000 | 0.298 | 0.679 | 121 |
| 단일 특징 규칙 (`DXP_HoldingPressure1 ≤ 200.1`) | 0.582 | 1.000 | 0.371 | 0.747 | 97 |
| 설정값(SET_*)만 쓴 LR | 0.917 | 1.000 | 0.298 | 0.679 | 121 |

설정값만 쓴 모델의 PR-AUC가 높은 것은 실험 계획(설정 조합)이 라벨을 거의 결정하기 때문이다. 실제 현장에서 설정만으로 불량이 정해지지 않으므로 서비스 입력은 실측 공정값을 쓴다.
