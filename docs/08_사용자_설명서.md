# 사용자 설명서 및 시연 가이드

무한루프 · 사출성형 품질위험 검토 v2.0 · 2026-11-21

## 1. 실행과 첫 화면

이 프로그램은 플라스틱 사출성형 **사이클(부품) 단위 공정값**을 받아, 먼저 검사할 부품과 학습 정상 범위를 벗어난 공정변수를 보여주는 연구용 MVP입니다. 설비 제어·출하판정·실시간 경고 시스템이 아닙니다.

저장소에는 빌드된 화면, 승격된 모델, 합성 예제가 들어 있어 원본 데이터 없이 실행할 수 있습니다. 프로젝트 루트의 PowerShell에서:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\setup.ps1
powershell -ExecutionPolicy Bypass -File .\scripts\start.ps1
```

브라우저에서 http://127.0.0.1:8765 를 엽니다. 첫 화면의 **합성 예제 결과 보기**는 합성 120부품을 바로 분석해 대시보드로 이동합니다. **데이터 업로드**는 직접 파일을 넣는 흐름입니다.

## 2. 파일 준비

| 열 | 필수 | 설명 |
|---|---|---|
| `part_id` | ✓ | 부품(사이클) ID. 파일 안에서 중복 불가 |
| `cycle_start_at`, `cycle_end_at` | ✓ | `2026-11-02 08:00:00` 형식 |
| `data_source` | ✓ | 실측 `ProBayes_IM_v2`, 합성 `synthetic_im`. 한 파일에 하나만 |
| `DXP_HoldingPressure1` | ✓ | 1단계 보압 실제값, bar |
| `CALC_InjectionStroke` |  | 사출 스트로크, mm. 비어 있으면 학습 중앙값으로 대체 |
| `material` |  | 재료 (PP, ABS 등) |
| `actual_label` |  | 실제 판정 0(정상)/1(불량). 예측에 쓰지 않고 결과와 비교만 |

- 한 행 = 사출 사이클 하나. 센서 시계열은 사이클별 값으로 먼저 집계합니다.
- 단위 변환은 하지 않습니다. 표의 단위로 입력하세요.
- 검사 결과·사후측정 열(`LBL_`, `IR_`, `CV_`, `SCA_`, `SIM_`, '불량'·'판정' 등이 들어간 이름)은 특징에 연결할 수 없습니다.
- CSV(UTF-8·CP949) 또는 xlsx 첫 시트, 10MB·10,000행·100열 이하.

모델이 바뀌면 필수 항목도 바뀔 수 있습니다. 화면의 항목 연결 표가 항상 현재 모델 기준입니다.

## 3. 업로드 → 항목 연결 → 검증

1. **데이터 업로드**에서 파일을 끌어 놓거나 예제(합성 / 오류 포함)를 불러옵니다.
2. **공통항목 연결**: 같은 이름과 원본 데이터셋 열 이름(`MET_MachineCycleID` 등)은 자동 연결됩니다. 필수 항목이 모두 연결되어야 검증할 수 있습니다. 각 특징의 단위와 허용 범위가 표시됩니다.
3. **데이터 검증**: 분석 가능 행, 제외할 행(이유 포함), 결측 대체 수를 확인합니다. 필수 특징이 비었거나 허용 범위를 벗어난 행, 중복 ID, 날짜 형식 오류, 0/1이 아닌 실제 판정은 제외됩니다. 연결을 바꾸면 검증 결과가 지워집니다.
4. **N행 분석 및 저장**을 누르면 예측하고 이력에 저장합니다.

## 4. 결과 보기

- **부품 검토 목록**: 위험 점수 높은 순. 점수 ≥ 기준(현재 0.252)이면 **우선 검토**, 아니면 통상 검토. 검토 구분·ID 검색으로 거를 수 있습니다.
- **오른쪽 패널**: 선택한 부품의 점수와 참고 구간을 벗어난 변수. **부품 상세 보기**에서 재료, 실제(합성은 가상) 판정, 결측 대체, 전체 입력값을 봅니다.
- **실제 판정과 비교**: `actual_label`이 있으면 불량 탐지 수, 우선 검토 중 불량 비율, 누락(FN)·추가 검토(FP)를 보여줍니다.
- 위험 점수는 보정된 추정 확률이지만 **실제 불량 여부가 아닙니다.** 참고 구간은 학습 정상 부품 5~95백분위이며 **공정 규격이 아닙니다.**
- **결과 CSV / 오류 CSV**로 내려받습니다.

## 5. 공정변수·모델 검증·이력

- **공정변수 분석**: 모델 입력(★)과 상위 후보 특징의 학습 분포, 값 구간별 불량 비율(5부품 이상 묶은 평균), 모델 입력 변수의 영향도.
- **모델 검증**: 모델 선택 기록표(4개 모델, Gate 1·2 통과 여부), holdout 혼동행렬과 기준선, 실험일 제외 진단. holdout은 **개발 참고 평가**입니다.
- **분석 이력**: 파일명·ID 검색, 자료 구분 필터, 저장 당시 결과 그대로 다시 열기.

## 6. 오류 대응

| 메시지 | 조치 |
|---|---|
| 필수 항목을 연결하세요 | 표에서 빠진 항목의 원본 열을 선택 |
| 검사 결과·사후측정·라벨 열을 공정 특징으로 연결할 수 없습니다 | 사이클 중 측정값 열을 연결 |
| 한 파일에 서로 다른 자료 출처를 섞을 수 없습니다 | 실측·합성 파일 분리 |
| 허용 범위 … 밖입니다 | 단위 확인 (예: bar 대신 MPa로 기록한 경우) |
| 필수 특징 누락 | 해당 행의 값 입력 |
| 파일은 10MB 이하 / 1~10,000행 | 파일 분할 |

## 7. 5분 시연

1. 홈 → **합성 예제 결과 보기** → 우선 검토 부품과 참고 구간 이탈 확인
2. **데이터 업로드 → 오류 포함 예제** → 검증에서 제외된 6행과 이유(중복 ID, 허용 범위, 필수 특징 누락, 날짜, 실제 판정 값) 확인 → 분석
3. 대시보드의 **가상 판정과 비교** 카드 확인 (합성 라벨은 가상값)
4. **모델 검증**에서 XGBoost가 CV 점수는 높지만 Gate 2에서 탈락한 이유 설명
5. **분석 이력**에서 이전 결과 복원, 결과 CSV 다운로드

## 8. 새 모델 반영 (개발자)

`scripts\setup.ps1 -Train` → 원본을 `ml_workflow\data\`에 받기 → `scripts\train.ps1 -Run <이름> -Promote` → 서버 재시작. 자세한 절차는 [문서 11](11_데이터_재현과_저장소_운영.md).
