# 사용자 설명서 및 시연 가이드

무한루프 · 제조공정 품질 분석 v1.0 · 화면 안내 갱신 2026-11-16

## 1. 실행과 첫 화면

이 프로그램은 자동차 부품 염욕 열처리 작업의 완료 후 집계자료를 분석합니다. 품질 담당자가 검토할 작업과 공정편차를 확인하는 연구용 MVP입니다. 설비 제어·출하판정·실시간 경고 시스템이 아닙니다.

GitHub에는 정적 화면 빌드와 모델, 독립 합성 예제가 포함되어 있습니다. 최초 설치를 마친 뒤 실행하세요. 프로젝트 루트의 PowerShell에서 실행합니다.

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\start.ps1
```

브라우저에서 `http://127.0.0.1:8765`를 엽니다. 종료는 서버 터미널의 Ctrl+C입니다. 다른 PC는 Python 3.12를 설치하고 다음을 한 번 실행합니다. 빌드된 화면이 포함되어 있어 일반 실행에는 Node.js가 필요하지 않습니다. 최초 Python 패키지 설치에는 인터넷이 필요합니다.

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\setup.ps1
```

개발자가 화면 소스를 수정했다면 Node.js와 pnpm 환경에서 `setup.ps1 -RebuildFrontend`를 실행합니다. 일반 사용자는 다시 학습하지 않고 동봉된 모델을 사용하면 됩니다. `/docs`는 API 개발자용 화면입니다.

첫 화면은 열처리 공정 품질 분석의 소개와 화면 예시를 보여줍니다. **데이터 업로드**로 파일 선택을 시작하거나 **합성 예제 결과 보기**로 120작업의 합성 예제를 즉시 분석·저장할 수 있습니다. 상단 메뉴로 각 기능을 이동하고 **무한루프** 로고를 누르면 첫 화면으로 돌아갑니다. 브라우저 뒤로·앞으로 이동 및 `#variables` 같은 화면 주소도 사용할 수 있습니다.

## 2. 파일 업로드와 항목 연결

상단 **데이터 업로드** → 파일 선택 또는 **합성 예제 불러오기**를 누릅니다. CSV는 UTF-8·CP949, Excel은 xlsx의 첫 번째 시트입니다. 제한은 10MB·10,000행·100열입니다. 한 행은 작업/LOT 한 개여야 하며 원시 센서 540MB 파일은 직접 올리지 않습니다.

**항목 연결**에서 원본 열과 공통항목을 연결합니다. 같은 이름은 자동 연결됩니다. 필수 항목은 작업 ID·시작/종료 시각·자료 출처와 36공정특성입니다. 품목·총수량·양품수량·불량수량은 선택입니다. 총수량과 불량수량을 함께 제공하면 실제 불량률을 표시하지만 예측에는 사용하지 않습니다. ID의 앞자리 0을 보존하려면 Excel에서 텍스트 형식으로 입력합니다.

온도는 °C, 출력 OP·CP는 %가 기본입니다. 원본이 °F/K 또는 0~1 비율이면 단위를 직접 선택하세요. 평균과 표준편차에 맞게 변환합니다. 숫자만으로 단위를 자동 추정하지 않습니다. 날짜는 `2022-06-03 13:08:54`처럼 연-월-일 형식이며 시간대가 없으면 한국시간입니다.

**데이터 검증**을 누릅니다. 유효행, 제외행, 결측 대체 수, 단위 변환 열을 확인합니다. 수정하려면 단계 표시의 **2 항목 연결**로 돌아갑니다. 이전 검증은 취소되므로 매핑·단위를 확인한 뒤 다시 검증해야 합니다. **N행 분석 및 저장**으로 실행합니다. **1 파일 선택**이나 상단 **데이터 업로드**를 누르면 현재 입력을 비우고 새 파일 선택을 시작합니다.

## 3. 결과와 상세 분석

**작업 검토** 화면은 위험 점수가 높은 순서의 목록과 선택한 작업의 상세 패널을 보여줍니다. **작업별 추이와 분석 요약 보기**를 펼치면 분석 작업 수·우선 검토 작업·평균 위험 점수·통계 구간 이탈 작업 수와 차트를 확인할 수 있습니다. 작업별 곡선은 완료된 작업의 순서이며 실시간 센서 파형이 아닙니다.

| 표시 | 뜻 |
|---|---|
| 위험 점수 0~1 | 모델의 상대적 위험 점수. 실제 불량률이나 보정된 불량 확률이 아님 |
| 우선 검토 | 현재 모델 점수 0.35 이상. 검사 우선순위 참고용 |
| 실제 불량률 (%) | 사용자가 제공한 불량수량÷총수량×100. 없으면 — |
| 가상 불량률 (%) | 합성자료에서 가정한 품질수량으로 계산한 값 |
| 통계 구간 이탈 | 학습 자료의 5~95백분위 밖. 기업 규격 위반이 아님 |

작업 ID를 누르면 우측 패널에서 기간·위험 점수·주요 편차를 봅니다. **전체 작업 상세 보기** 또는 목록의 상세 버튼을 누르면 품질 결과·결측 대체·전체 편차 목록이 열립니다. **전체 공정 입력값 확인**에서 원본 숫자와 실제 추론값을 비교할 수 있습니다. 통상 검토 또는 편차 없음도 품질 정상 판정을 뜻하지 않습니다. 검색·검토 구분 필터를 이용하고 결과 CSV를 내려받습니다. 오류행이 있으면 하단에서 이유와 오류 CSV를 확인합니다.

## 4. 변수·모델·이력 화면

**공정변수 분석**은 학습 78작업의 변수 분포와 검증 자료에서의 영향변수를 보여줍니다. GitHub 버전의 품질 관계 차트는 5작업 이상을 묶은 집단 평균입니다. 원본 작업별 산점도와 구분해 표시합니다. 분석 변수를 바꾸어 확인합니다. 상관계수나 영향값은 원인이 확정됐다는 뜻이 아닙니다.

**모델 검증**은 3종 비교, 위험 누락/FN, 오경고/FP, 단순 기준선과 한계를 보여줍니다. 재현율·정밀도 등은 **추가 평가 지표**를 펼쳐 확인합니다. 보류자료 36작업 중 위험 7작업에서 5건을 탐지했으나 23건의 오경고가 있었습니다. 현장 적용 성능을 입증한 결과가 아닙니다.

**분석 이력**에서 파일명·분석 ID·자료 출처로 검색하고 **결과 보기**를 누르면 당시 저장한 결과를 다시 엽니다. 재학습하거나 점수를 다시 계산하지 않습니다. 과거 버전 기록에는 전체 입력값과 생성시각이 없을 수 있습니다.

## 5. 오류 대응과 5분 시연

| 상황 | 조치 |
|---|---|
| 필수 연결 누락 | 필수 40개 항목의 원본 열을 연결 |
| 같은 작업 ID 중복 | 두 행 모두 제외되므로 중복 원인을 확인해 파일 수정 |
| 문자·무한값·음의 표준편차 | 원본 수치/단위 수정 |
| 특성 결측 4개 이상 | 원천 자료 보완. 3개 이하는 학습 중앙값 대체 |
| 총수량과 품질수량 불일치 | 총량·양품·불량 합계 확인 |
| 실측·합성 혼합 | 각각의 파일로 나누고 출처 확인 |
| 서버 연결 오류 | 서버 터미널 확인, 8765 포트와 주소 확인 |
| 포트 사용 중 | `start.ps1 -Port 8770`으로 실행 후 해당 주소 접속 |

시연 순서: ① 합성 기능 예제 선택과 미리보기(1분), ② 필수 연결·단위·검증(1분), ③ 분석·우선 검토 작업·상세 편차(1분), ④ 변수 분포·3모델 비교와 낮은 성능 설명(1분), ⑤ 이력 복원·CSV와 합성 구분(1분).

발표 문장: “저희는 제조 데이터를 올리고 항목을 연결하면, 작업별 품질위험 점수와 통계적 공정편차를 함께 확인하고 결과를 저장하는 웹 MVP를 구현했습니다. 현재는 작업 완료 후 예측이며, 작업별 품질자료 136건에서 현장 성능까지 확보한 것은 아닙니다. 누락과 오경고를 함께 공개하고 신규 현장자료로 추가 검증할 계획입니다.”

자료 출처: 중소벤처기업부 KAMP, 스마트제조혁신추진단(㈜임픽스), 「열처리 품질보증 AI 데이터셋」(2022-12-23). 원본·개인화 가이드북은 재배포하지 않습니다. 합성 기능자료는 실제 성능 평가에 사용하지 않습니다.

## GitHub Clone 환경의 예제

첫 화면에서 **합성 예제 결과 보기**를 선택하면 120행의 독립 합성자료를 분석·저장합니다. 파일 연결부터 시연하려면 **데이터 업로드 → 합성 예제 불러오기**를 선택하세요. 실측 예제는 재배포하지 않아 Clone 환경에서 비활성화됩니다. 합성 수치와 가상 품질수량은 코드에서 별도로 생성했으며 학습·정확도 평가에 사용하지 않습니다. 기존 로컬 실측 예제가 있는 환경에서는 실측 기능도 유지됩니다. [공유 기준](../DATA_USAGE.md)을 참고하세요.
